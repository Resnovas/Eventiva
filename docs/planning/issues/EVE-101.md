## Linear description

## Goal

An organiser sees what crew and staff cost for each event and phase against budget, from rostered (forecast) through approved (accrued) to paid (actual), without seeing any individual's pay.

## Context

* Parent: <issue id="335d2890-1b10-44eb-89f0-b9a032afacfa" label="EVE-61" href="https://linear.app/resnovas/issue/EVE-61/f12-payroll-pay-staff-and-crew-from-rosters-and-approved-timesheets" />, sections 4, 6 and 9. Events and phases are F1's; budget lines are F11's.
* Charts and saved dashboards come from <issue id="1d65d374-8d06-4d69-a9c6-f3b66d565b47" label="EVE-30" href="https://linear.app/resnovas/issue/EVE-30/port-data-widgets-saved-dashboards-and-brand-kits" /> once ported; until then a Rambo-UI table and chart.

## Scope

1. `payroll.report.labourCost`: group by event, phase, role, department or period; three columns: forecast (rostered shifts times rate card), accrued (approved timesheets), actual (locked runs).
2. Aggregation hides individuals: groups of fewer than 3 workers are merged for viewers without `payroll:read`.
3. "Labour cost" screen with projection and bindings; the agent reads the same projection.
4. Export to CSV through the same action.

## Acceptance criteria

* For the fixture, actual by event sums to the run gross and matches the F12.7 journal.
* An organiser asking the agent "what did crew cost for the load-out" gets the phase total and cannot get a per-person figure.
* Forecast updates when a shift is added to the roster (change feed), in a test.

## Constraints

Effect-TS v3; no zod; behind the `payroll` flag; no new dependency without approval on this issue; ships to main with `node --run check` results pasted here.
