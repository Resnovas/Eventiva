## Goal

The agent keeps HR compliant without being asked: it spots expiring certificates and checks before a show, chases overdue onboarding, flags leave clashes, reads uploaded certificates for a person to confirm, and HR has headcount, compliance and leave reports on one dashboard.

## Scope

1. Actions `hr.reports.headcount`, `hr.reports.compliance`, `hr.reports.leave` and the `hr.compliance` dashboard built from <issue id="1d65d374-8d06-4d69-a9c6-f3b66d565b47" label="EVE-30" href="https://linear.app/resnovas/issue/EVE-30/port-data-widgets-saved-dashboards-and-brand-kits" /> widgets.
2. Expiry watch: a daily durable run per tenant listing qualifications and right-to-work follow-ups expiring within 60 days or before any rostered F1 Event date; drafts reminders to workers and agencies and flags affected F2 roster slots into a review queue for HR.
3. Roster guard: on F2 assignment, explains `NotEligible` reasons in plain words with the next step (upload, verify, request override).
4. Onboarding chase: morning summary of overdue steps with suggested reminders; nothing is sent without the HR user's confirmation unless the tenant enables auto-send.
5. Leave clash summary for approvers on each request.
6. Evidence reading: on certificate upload, the agent proposes type, issuer, reference, issue and expiry dates; the person confirms; `hr.qualifications.verify` stays human-only.
7. Agent descriptions for every HR action written for the agent, including which actions are human-only (sign, acknowledge, verify, approve leave, end engagement, offboard, revoke, override, purge).
8. Evaluations (<issue id="bef04957-8bec-479e-85ee-5880dfc9fc8c" label="EVE-29" href="https://linear.app/resnovas/issue/EVE-29/port-agent-evaluations-linked-to-posthog-datasets" />): at least 20 HR tasks (for example onboard 30 freelancers, find riggers for Saturday, book leave, explain why someone is ineligible) with expected action sequences and refusals.
9. Each proactive behaviour behind its own flag, default off.

## Acceptance criteria

* With a rigging competent person certificate expiring before a rostered Event, the expiry watch produces one review item linking the worker, the certificate and the roster slot.
* The agent never calls a human-only action in the evaluation set, and refuses with a clear message when asked to.
* Evidence reading on 10 sample certificates fills the right fields for at least 8, and every result waits for human confirmation.
* Sensitive fields never appear in agent context during the evaluation run (assertion from F13.2).
* The compliance dashboard counts match `hr.reports.compliance`.
