## Goal

When the venue network fails, every registered scanner keeps admitting and rejecting correctly, and after reconnect the server reconciles all scans with no lost entries and clear alerts for any double entry.

## Scope

1. ticketing.device.snapshot: per device and list, a signed snapshot of ticket validity (id, type, status, holder name, secret hash) plus event public keys and a revocation list; delta refresh every 30 seconds online; expiry per list (default 24 hours).
2. Local scan ledger in SQLite: append-only, queued for upload, each scan with device clock, monotonic counter and offline flag.
3. Device-side validation using the shared function from F8.5; unknown ticket with a valid signature and no void in the snapshot is admitted with a warning (issued after last sync).
4. Peer-free consistency: no device-to-device sync in this slice; devices at the same gate converge through the server on reconnect.
5. Server reconciliation: union of ledgers, ordering by server receive time then device counter; for single-entry lists later admits become duplicate-entry alerts; admits of tickets voided before the scan become void-admit alerts. Alerts are change-feed events shown on devices and in the agent thread.
6. Device revocation: a revoked device's uploads are accepted for audit but marked, and its snapshot stops refreshing.
7. Offline indicator, queued count and last sync time on the Scanner screen.

## Acceptance criteria

* Two devices offline for 30 minutes scan 2,000 fixture tickets including 20 deliberate cross-device duplicates: after reconnect, zero lost scans, exactly 20 duplicate alerts, admitted counter correct.
* A ticket issued after a device's last sync admits offline with a warning; a forged payload is rejected offline.
* A ticket voided before the device went offline is rejected offline; one voided while it was offline raises a void-admit alert after sync.
* Device restart while offline keeps the queue (persisted) and the snapshot.
* Offline scan to result p95 under 300 ms on a mid-range Android device.
