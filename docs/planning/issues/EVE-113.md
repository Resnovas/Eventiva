## Goal

Anyone can browse published listings on the open web, and search engines can index them, without signing in or installing anything.

## Context

* Decision D5-5 default: a public, indexable directory section on its own subdomain (<issue id="5c7aeec2-d49c-4028-9eca-1bc641d3618c" label="EVE-13" href="https://linear.app/resnovas/issue/EVE-13/establish-modular-core-foundations-for-database-adapters-expo-and" /> allows web sections on separate subdomains with independent updates).
* Reads go through the same actions (`directory.search`, `directory.listing.get`, `directory.availability.check`) over the HTTP API from <issue id="0ab161c4-ed9c-4581-86fe-91fa1f4216aa" label="EVE-46" href="https://linear.app/resnovas/issue/EVE-46/p17-build-the-http-api-streaming-and-the-typed-client-from-the-action" />, as an anonymous principal with public permissions only.
* The same React Native screens render on web through react-native-web (<issue id="91297309-acc4-4bb9-ad68-33fbc2720e5a" label="EVE-50" href="https://linear.app/resnovas/issue/EVE-50/p111-build-screen-awareness-app-state-navigation-and-the-screen" /> decision); this section adds server rendering for anonymous pages.

## Scope

1. A web app section for the directory with routes: category landing, search results, listing detail, ranking parameters page, report content page.
2. Server-side rendering of listing detail and category pages with canonical URLs, structured data ([schema.org](<http://schema.org>) LocalBusiness or EventVenue as appropriate), sitemap and robots rules; unpublished or suspended listings return 410.
3. Anonymous principal in <issue id="7f612e80-3332-4acf-a74c-d35db06fe4e8" label="EVE-43" href="https://linear.app/resnovas/issue/EVE-43/p14-build-identity-and-access-orgs-authorization-user-profiles-and" /> with read-only public permissions and rate limits.
4. "Start an enquiry" for anonymous visitors routes to sign-in or sign-up, then to the enquiry composer in the app with the listing preselected.
5. Cookie and analytics consent banner before any PostHog capture on this section; telemetry: false honoured.
6. Lighthouse budgets: performance 90, accessibility 100 on listing detail.

## Acceptance criteria

* Listing detail renders without JavaScript enabled and passes axe with no violations (report attached).
* A suspended listing returns 410 within one change-feed cycle.
* No private field reaches the HTML (test reads the rendered page for every field marked private).
* Anonymous calls cannot reach any non-public action (negative test on the HTTP surface).

## Constraints

Effect-TS v3 for server code; Rambo-UI; whitelabel ASCII copy; sub-flag `directory-public-web` default off; no new dependency (for example a server-rendering framework) without Jonathan approving it on this issue; ships to main with `node --run check` results pasted here.

## Done signal
