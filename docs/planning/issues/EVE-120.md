## Linear description

Decided 2026-11-08 (Jonathan): D-F10-1 is MapLibre with open map tiles. This spike now confirms it; it falls back to the alternatives only if a criterion fails.

## Goal

Prove, on a throwaway `spike/*` branch, that one map engine renders a geo-referenced site with editable features on Expo web and an Android device, works offline from a downloaded region, and keeps feature edits in a Yjs document that two clients share.

## Scope

1. Expo development build (not Expo Go) with the engine on Android and web from one React Native component tree. maplibre-react-native v11 needs the new architecture and React Native 0.80 or later, and has no web target, so web uses maplibre-gl-js behind the same MapEngine port with one shared style spec (checked 2026-11-08).
2. A fixture site: 1 km2 OpenStreetMap PMTiles extract served locally, one raster imagery source, one calibrated PNG plan overlay.
3. 2,000 fixture features (points with symbols, fence lines, zone polygons) in one Yjs document per layer; drag, rotate and delete update Yjs, and Yjs updates redraw the map.
4. Two clients (web and Android) on a local y-websocket or the <issue id="60101c56-d4e4-4e4f-b7c8-b4c40f44ada0" label="EVE-17" href="https://linear.app/resnovas/issue/EVE-17/s4-choose-the-offline-sync-engine-for-record-edits-and-live-text-and" /> stack; one goes offline, both edit, both converge.
5. Offline: download the region as a per-site PMTiles extract opened with `pmtiles://file://` (not the tile-by-tile offline manager), plus overlay and layer docs; switch to airplane mode, restart the app, edit. On web, prove the same extract works from a service worker cache after a reload with the network off.
   5a. Editing handles: neither MapLibre client ships editing tools on device, so build the drag, rotate and vertex handles as an Eventiva gesture layer and measure it; test Terra Draw on web only.
   5b. Concurrent edits: an offline client moves a feature, an online client moves it later; record which wins (Yjs orders by logical clock and client id, not time) and show the change notice.
6. Record frame time while panning with 2,000 features on a mid-range Android device, and bundle size added on web.
7. Plan-only mode (<issue id="f8432c08-24bb-4690-a3e1-16ed79977eee" label="EVE-108" href="https://linear.app/resnovas/issue/EVE-108/f10-interactive-site-maps" /> scope note, 2026-11-08): with the basemap off, render a three-level building fixture (walls, rooms, doors, stairs) in the site-local metric frame, switch levels, and show the level below ghosted; measure frame time with 10,000 plan features. If MapLibre cannot do this well, record the gap and test a Skia renderer for plan-only sites behind the same MapEngine port.
8. Check the tile and imagery licences for offline caching and printing, and record the result. Desk check done 2026-11-08 (<issue id="f8432c08-24bb-4690-a3e1-16ed79977eee" label="EVE-108" href="https://linear.app/resnovas/issue/EVE-108/f10-interactive-site-maps" /> section 8): Mapbox and Esri imagery cannot go into MapLibre offline packs, MapTiler self-hosted imagery is sales-only; the spike uses a local orthophoto fixture as the offline imagery layer (D-F10-6).

## Acceptance criteria

* Screen recording of web and Android showing the fixture, an edit on each converging, and the offline restart.
* Frame-time numbers (median and p95) and web bundle delta in the issue.
* A pass or fail per criterion for MapLibre, and for the fallback if MapLibre fails any.
* A recommendation comment that confirms or changes D-F10-1.
