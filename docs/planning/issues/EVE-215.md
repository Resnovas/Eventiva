## Linear description

## Goal

Staff, customers and the agent can request a full or partial refund, cancellation or exchange; a person with the right role approves it; money goes back through the original payment method, stock and tickets are released, and accounting is told.

## Context

* Parent <issue id="7d939472-20ba-4512-b231-c0f04c05574c" label="EVE-107" href="https://linear.app/resnovas/issue/EVE-107/f9-online-and-in-person-sales-storefront-point-of-sale-orders-payments" /> sections 4, 7 and 11. Agent approval policy: refunds and voids are `always` for agents, `confirm` for people with sales:refund:approve.
* Releases go through each line provider (F8 ticketing.ticket.void, F6 inventory.reservation.release with restock).

## Scope

1. Refund state machine: requested, approved, rejected, processing, completed, failed.
2. Actions: sales.refund.request (lines, quantities or amount, reason, restock flag), approve, reject; sales.order.cancel for unpaid or unfulfilled orders; exchange as refund plus new order linked by `exchangeOf`.
3. Refund to the original method: card online and card present through the PaymentGateway, cash from the register session (CashMovement out), gift card re-credit (F9.9), on-account orders handed to F11 as a credit note request.
4. Per-product refund policy (days allowed, exempt) shown at checkout (F9.4) and enforced at request time with an override that needs approval.
5. Disputes: chargeback webhooks create a Dispute record (opened, evidence due, won, lost) with evidence fields; no automatic evidence submission in this slice.
6. Line provider release on refund; partial refunds release only affected lines.
7. Events sales:refund_completed and sales:dispute_updated on the change feed for F11.
8. Customer self-service refund request on their order page.

## Acceptance criteria

* Agent requests a partial refund on a two-line order; it waits for approval; a sales manager approves; the fake gateway refunds; the ticket line is voided and the stock line restocked; F11 event emitted.
* Refund outside the policy window is rejected unless overridden with approval.
* Cash refund changes the session's expected cash.
* Webhook replay of a dispute changes nothing.
