## Linear description

## Goal

Each department writes its numbered cue list against the run of show, and exports it as paperwork or as a file its console or playback system imports.

## Context

* Parent: <issue id="fbcff205-decd-464a-b8ab-a1278e71fbe4" label="EVE-73" href="https://linear.app/resnovas/issue/EVE-73/f1-events-and-production-planning-the-event-record-run-of-show" /> sections 4, 5 (Cue, CueList), 6 (Cue list screen), 8 (`ConsoleExport` port).
* Cues are planning data here. Firing them live is F1.13; timecode placement is F1.12.

## Scope

1. Tables `cue_list` (event_id, department_id, name, numbering scheme) and `cue` (number as a decimal string such as `12`, `12.5`; label; segment_id; trigger: manual, follow with delay, timecode; target action ref for F1.13; notes; sort by number then sort_key).
2. Actions: `cueList.create`, `cue.create`, `cue.update`, `cue.renumber` (explicit, never automatic), `cue.delete`, `cue.export`.
3. Duplicate cue numbers created offline both survive and are flagged; export refuses while duplicates exist.
4. `ConsoleExport` port with these first adapters: CSV (number, label, segment, notes), PDF paperwork through <issue id="8d8d301b-d679-4dac-95bb-c24889179cd0" label="EVE-25" href="https://linear.app/resnovas/issue/EVE-25/port-files-private-attachments-artifacts-and-document-import" />, and an OSC command script (one line per cue). Console-specific import formats are listed as follow-up adapters after the first real console is named by a user; each one is its own issue.
5. Agent: drafts cue lists from segment notes, flags cues pointing at deleted segments.
6. Screen: Cue list (numbered list, linked segment, trigger and target columns, export menu) with projection and bound controls.

## Acceptance criteria

* Point cues sort correctly (`1`, `1.5`, `2`, `10`).
* Two offline creates of cue `5` both survive and are flagged; export fails with a typed error until renumbered.
* CSV and PDF exports match committed snapshots.
* The agent drafts a lighting cue list for a 10 segment run of show; every cue links to an existing segment.
* Screen passes the unbound-control check and axe.

## Constraints

Effect-TS v3 house rules (the cue number comparator is pure TypeScript); every operation is an inventory action with one permission check, audit and change record; UI from Rambo-UI, WCAG 2.2 AA; behind PostHog flag `f1-production-plans`; PDF rendering uses whatever <issue id="8d8d301b-d679-4dac-95bb-c24889179cd0" label="EVE-25" href="https://linear.app/resnovas/issue/EVE-25/port-files-private-attachments-artifacts-and-document-import" /> provides, no new dependency without Jonathan approving it on this issue; whitelabel ASCII copy; people docs and ai-docs in the same commit; ships to main with `node --run check` results here.
