## Goal

Organisers, finance and safety officers see sales, sell-through and live admissions per Event and admission scope, and can export attendee lists within the data rules.

## Context

* Parent <issue id="8bd88b8d-9173-4f07-a92d-1c317836f4b2" label="EVE-76" href="https://linear.app/resnovas/issue/EVE-76/f8-ticketing-ticket-types-capacity-issuance-admissions-and-scanning" /> sections 4, 6, 10, 11. Revenue truth lives in F9 orders and F11 ledgers; F8 reports units and face value and links to F9 for money.

## Scope

1. Actions: ticketing.report.sales (units, face value, by ticket type, channel, day), ticketing.report.admissions (admitted by gate and time bucket, no-shows), ticketing.export.attendees (CSV via <issue id="8d8d301b-d679-4dac-95bb-c24889179cd0" label="EVE-25" href="https://linear.app/resnovas/issue/EVE-25/port-files-private-attachments-artifacts-and-document-import" />, chosen fields, always logged in audit).
2. Read models fed from the change feed (<issue id="ee08644c-eb3c-4a46-aea7-745864ad4263" label="EVE-45" href="https://linear.app/resnovas/issue/EVE-45/p16-build-the-change-flow-domain-events-and-a-durable-resource-change" />) so reports do not load the pool entities.
3. Sales dashboard with <issue id="1d65d374-8d06-4d69-a9c6-f3b66d565b47" label="EVE-30" href="https://linear.app/resnovas/issue/EVE-30/port-data-widgets-saved-dashboards-and-brand-kits" /> widgets: sell-through against capacity and target, pace curve, live admitted count per gate for safety.
4. Retention job: attendee personal data on a finished Event is minimised after the configured period (default 12 months), keeping aggregate counts.

## Acceptance criteria

* Report totals equal the sum of tickets in a fixture event; admissions match the scan ledger.
* Export by a role without ticketing:manage is denied on every surface; each export writes an audit record with the field list.
* Retention job removes holder names, emails and answers after the period and leaves counts intact.
* Agent answers "how many people are in through gate B" from the admissions report with the same number the dashboard shows.

## Constraints

Effect-TS v3 house rules; no personal data in PostHog; behind flag `ticketing`; no new dependency without Jonathan approving it here; ships to main per the AGENTS.md delivery exception with `node --run check` results pasted here.
