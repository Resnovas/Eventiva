## Goal

Every person on an event day gets one call sheet with their call time, place, contacts and the day's schedule, readable offline, and the production team knows who has read it.

## Context

* Slice 7 of F2 (<issue id="1c8c53a0-396b-43a7-8fb9-c138dbbc70b2" label="EVE-67" href="https://linear.app/resnovas/issue/EVE-67/f2-scheduling-and-rosters-crew-availability-shifts-offers-call-sheets" /> sections 4 to 6). Draws from F1 Event, Itinerary and Run of show, and from confirmed Assignments.
* Notes are a Yjs document embedded in the CallSheet record (<issue id="a1348819-43cc-4005-8e8d-a896a761af03" label="EVE-51" href="https://linear.app/resnovas/issue/EVE-51/p112-build-collaboration-yjs-for-text-and-canvas-with-record-sync-and" />); PDF export through files (<issue id="8d8d301b-d679-4dac-95bb-c24889179cd0" label="EVE-25" href="https://linear.app/resnovas/issue/EVE-25/port-files-private-attachments-artifacts-and-document-import" />).

## Scope

1. `callsheet.generate` builds a draft for an Event and date: venue and address, parking and access notes, weather placeholder, Run of show for the day, per-person call times grouped by department, key contacts, emergency info.
2. `callsheet.update` edits sections; notes are collaborative.
3. `callsheet.publish` (agent confirm) freezes an immutable CallSheetVersion and notifies recipients; republish creates a new version with a change summary.
4. `callsheet.acknowledge` records read receipts; production sees who has not acknowledged.
5. `callsheet.export` to PDF; each person's PDF highlights their own call time.
6. Offline: assignees download published versions for the next 14 days; viewing works in airplane mode.
7. Contact details shown only to people working that day.

## Acceptance criteria

* Generate, edit with two people, publish, acknowledge: version history shows both versions and the diff summary.
* A crew member opens the latest version offline on Android and web.
* A person not on the day cannot read it (negative test on every surface).
* The agent builds tomorrow's call sheet on request and asks before publishing.

## Constraints

Effect-TS v3; whitelabel ASCII templates; localization-ready strings (<issue id="338aae77-d10e-4f8a-9189-fe3655bd3572" label="EVE-28" href="https://linear.app/resnovas/issue/EVE-28/port-localization-for-people-and-for-the-agent" />); behind flag `f2-scheduling`; no new dependency without approval here; ships to main with `node --run check` results pasted here.
