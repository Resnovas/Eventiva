## Linear description

## Goal

Remove Eventiva's temporary exception from the house AI-credit ruleset gates, and restore Copilot code review and the Code Quality merge gate, once the owner has approved appropriate budgets.

## Context

* <issue id="583894b0-6b9f-4759-8b2d-145a78d15933" label="EVE-243" href="https://linear.app/resnovas/issue/EVE-243/fully-enrol-eventiva-in-smartcloud-house-synchronization" /> put Eventiva on `Resnovas/.github/smartcloud/house-base.yml` instead of `house.yml`. The base preset has every house rule except `settings.ruleset.copilotReview` and `settings.ruleset.codeQuality`, both of which spend GitHub AI credits.
* This was needed because the Resnovas Actions and all-AI-credit budgets are held at USD 0 with hard stop after the 2026-11 billing lock. The September charge came from Code Quality AI credits.
* The override lives after the `house:local` line of Eventiva's `.github/smartcloud.yml`: `sync.values.HOUSE_PRESET: house-base.yml` and `settings.ruleset.copilotReview: false`. The managed `extends` line points at `house-base.yml`. Process: `Resnovas/.github` docs/preset.md#base.

## Work

1. The owner approves non-zero monthly AI-credit (and, if needed, Code Quality licence) budgets in GitHub Billing, with hard stop and alerts. Record the amounts, scope and evidence here, without payment details.
2. The owner decides to restore paid Copilot review and Code Quality on Eventiva.
3. In Eventiva, remove `sync.values.HOUSE_PRESET` and `settings.ruleset.copilotReview: false`, and point the managed `extends` line back at `Resnovas/.github/smartcloud/house.yml@main`. Update docs/smartcloud-enrollment.md.
4. Validate with the Smartcloud CLI (`validate`, `plan settings`): the effective config must match `house.yml` with `codeQuality: errors` and `copilotReview: true`. Push under the direct-main exception and read back the `house: default branch` ruleset.

## Acceptance

* Approved budgets are recorded here.
* Eventiva's effective config is identical to every other house repository's, and the live ruleset contains the `code_quality` and `copilot_code_review` rules.
* AI-credit spend is reviewed one billing cycle after restoration.

## Out of scope

Raising any budget without the owner's explicit approval.

## Done signal

Eventiva extends `house.yml` with no local AI-gate override, and the ruleset read-back shows both gates.
