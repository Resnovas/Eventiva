## Linear description

## Goal

Sites, pages and their content exist as records and collaborative documents that people and the agent edit through the same block-level actions, with every block type defined once in Rambo-UI with a typed property schema.

## Scope

1. Tables and schemas: Site (kind event, organisation, venue, vendor; subdomain unique across the platform; locales; brandKitId), Page (path unique per site and locale, parent, seo, binding), Menu.
2. Block tree inside the page doc: node id, blockType, props, children, bindings. A `BlockRegistry` service maps blockType to its Effect Schema for props, allowed children, editor hints (icon, category, which props are inline-editable) and a renderer.
3. A Rambo-UI `site-blocks` package (in Resnovas/Rambo-UI, no Eventiva dependency) with the static blocks: section, columns, heading, rich text, image, gallery, video embed, button, spacer, divider, accordion, tabs, card grid, hero, quote, map embed placeholder, custom embed (sandboxed iframe with an allow list). Data-bound blocks come in F14.9.
4. Actions `sites.create/update/archive/get/list`, `pages.create/update/move/duplicate/delete`, `pages.blocks.insert/update/move/remove`; block actions validate props against the registry and apply a Yjs update, so a block edit by the agent and a drag by a person are the same operation with undo (change record).
5. Migration of block props: each block schema is versioned; a stored node with an older version is upgraded by a pure migration on read.
6. Permissions `sites:read/edit/manage` via <issue id="7f612e80-3332-4acf-a74c-d35db06fe4e8" label="EVE-43" href="https://linear.app/resnovas/issue/EVE-43/p14-build-identity-and-access-orgs-authorization-user-profiles-and" />; vendor and venue profile sites (F5) restrict editing to unlocked blocks.
7. Offline: sites, pages and menus sync; page docs merge by CRDT; path collisions detected at publish (F14.10), not at edit.

## Acceptance criteria

* Two clients and the agent insert, move and edit blocks on one page concurrently, one offline, and converge (test reusing the <issue id="a1348819-43cc-4005-8e8d-a896a761af03" label="EVE-51" href="https://linear.app/resnovas/issue/EVE-51/p112-build-collaboration-yjs-for-text-and-canvas-with-record-sync-and" /> harness).
* Inserting a block with invalid props fails with `BlockPropsInvalid` on UI, HTTP and MCP.
* A federated test module registers a block type on activation and removes it on disposal; pages using it show a placeholder while it is unavailable.
* Rambo-UI `site-blocks` has no import of any Eventiva package (lint).
