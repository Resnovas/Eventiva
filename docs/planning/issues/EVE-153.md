## Goal

HR picks a template, starts onboarding for one worker or thirty, and every step (documents to sign, certificates to upload, account invite, tasks, training) is tracked to done; leaving runs the same way and removes access on the leave date.

## Scope

1. Tables OnboardingTemplate (versioned, per worker type), OnboardingRun, OnboardingStep (kind, owner, due offset, dependency, set-once completion), and the same shape for offboarding.
2. Step kinds: generate-and-sign document (F13.3), upload document, add qualification (F13.5), right-to-work check (F13.6), create task (F3), send account invite, acknowledge policy, custom checkbox.
3. Actions `hr.onboardingTemplates.create` / `.update`, `hr.onboarding.start` (bulk-capable: many workerIds in one call, one approval), `hr.onboarding.completeStep`, `hr.onboarding.cancel`, `hr.invites.send`, `hr.offboarding.start`, `hr.access.revoke`.
4. Worker status moves candidate to onboarding on start and onboarding to active when every required step is done; offboarding moves to left on the leave date.
5. `hr.access.revoke` at the leave date ends memberships, revokes agent delegations and external agent tokens for that person (<issue id="7f612e80-3332-4acf-a74c-d35db06fe4e8" label="EVE-43" href="https://linear.app/resnovas/issue/EVE-43/p14-build-identity-and-access-orgs-authorization-user-profiles-and" />), effective in running sessions.
6. Starter templates: employee, freelancer, volunteer, agency crew.
7. `hr.onboarding` board screen with projection and bound controls per <issue id="253839bc-c987-416b-92ea-206c9e9e8d2e" label="EVE-80" href="https://linear.app/resnovas/issue/EVE-80/f13-human-resources-worker-records-onboarding-qualifications-and-leave" /> section 6.

## Acceptance criteria

* Starting onboarding for 30 freelancers in one agent call asks for one confirmation, creates 30 runs and sends 30 invites.
* A run with a sign step and an upload step completes only when both are done; the worker becomes active.
* Completing the same step offline on two devices records one completion and one no-op.
* At the leave date the person's sessions and agent delegations stop working within one minute (test with a running session).
* Runs survive a runner kill mid-run (<issue id="a626308a-598f-41ba-accd-4004cbbd9932" label="EVE-54" href="https://linear.app/resnovas/issue/EVE-54/p18c-build-durable-agent-runs-on-effect-cluster-and-workflow" /> recovery).
