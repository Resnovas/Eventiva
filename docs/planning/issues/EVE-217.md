## Linear description

## Goal

People build pages by dragging blocks on a live canvas on web, tablet and desktop, and edit the same pages comfortably on a phone, with presence, undo and the agent alongside, all driving the same block actions.

## Scope

1. Rambo-UI components (no Eventiva dependency): `CanvasSurface` (renders a block tree with selection outlines, drop indicators, keyboard move), `LayersTree` (outline with drag reorder), `PropertyInspector` (form generated from the block's Effect Schema props through neutral schema descriptors), `BlockPalette` (categories, search).
2. Drag and drop with pointer and touch on wide screens; full keyboard alternative (select, cut, paste, move up and down, into and out of containers) to meet WCAG 2.2 AA 2.5.7 Dragging Movements.
3. Phone layout: structured editor (block list with reorder handles plus a bottom property sheet); same actions.
4. Inline text editing in rich text and heading blocks on the Yjs text type; image replace from <issue id="8d8d301b-d679-4dac-95bb-c24889179cd0" label="EVE-25" href="https://linear.app/resnovas/issue/EVE-25/port-files-private-attachments-artifacts-and-document-import" /> media.
5. Viewport preview toggles (phone, tablet, desktop) and locale switch.
6. Presence avatars and remote selections; per-user undo and redo.
7. Agent panel docked in the editor: instructions apply to the current selection or page (F14.12 supplies generation; this slice wires the panel and the projection).
8. Unsaved state does not exist: every change is a synced doc update; a "Draft" badge shows until publish.

## Acceptance criteria

* On web, drag a hero and a columns block, edit text inline, and undo three steps; on Android the same page is editable in the structured layout and both views converge live (test plus recorded device check).
* Every editor operation can be done with the keyboard only (axe and a scripted keyboard test).
* The agent reads "the selected block is the second card in the pricing section" from the projection and changes its button label through `pages.blocks.update`.
* The unbound-control check from <issue id="91297309-acc4-4bb9-ad68-33fbc2720e5a" label="EVE-50" href="https://linear.app/resnovas/issue/EVE-50/p111-build-screen-awareness-app-state-navigation-and-the-screen" /> passes for the editor.
