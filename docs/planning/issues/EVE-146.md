## Linear description

## Goal

An organiser or the agent creates a site, adds indoor levels, and lays satellite imagery, an uploaded image, a PDF or a DXF drawing under it, calibrated so every later measurement is in true metres.

## Scope

1. Tables `sitemap_site`, `sitemap_site_level`, `sitemap_base_layer` in a `type:extension` package with Drizzle schema through the shared schema package (<issue id="c31b6b08-1532-4a7a-945f-24a70bbab765" label="EVE-23" href="https://linear.app/resnovas/issue/EVE-23/split-core-into-portable-contracts-and-backend-runtime-with-a-shared" />), `tenant_id` on every row, synced per <issue id="a1348819-43cc-4005-8e8d-a896a761af03" label="EVE-51" href="https://linear.app/resnovas/issue/EVE-51/p112-build-collaboration-yjs-for-text-and-canvas-with-record-sync-and" /> record sync.
2. Actions: `sitemap.site.create`, `.update`, `.archive`; `sitemap.level.add`, `.update`, `.remove`; `sitemap.baseLayer.add`, `.calibrate`, `.remove`. Each with Effect Schema input and output and tagged errors (`SiteNotFound`, `CalibrationUnderdetermined`, `CalibrationResidualTooHigh`, `UnsupportedDrawing`).
3. Site-local frame: origin = site anchor, x east and y north in metres, with pure conversion functions to and from WGS84 (local transverse Mercator around the anchor) in the shared contracts package, so F1 and others can import them on client and server.
4. Calibration: affine transform from two or more control points (two points: similarity; three or more: least-squares affine), residual in metres; the residual is fit quality only, so the screen also states that absolute accuracy is limited by the imagery or survey control it was fitted to; reject above a tenant setting (default 1.0 m, <issue id="9d08c369-bac9-4eb7-b8a7-329b5ec9bff0" label="EVE-41" href="https://linear.app/resnovas/issue/EVE-41/p12-build-app-config-settings-secrets-and-credentials" />).
5. `DrawingImport` port with a neutral Effect service: PDF page to raster tiles, DXF to GeoJSON lines in drawing units, GeoTIFF orthophotos (drone or survey) to georeferenced raster tiles; a DWG upload is refused with a request for a DXF or PDF export (open DWG readers are GPL, the ODA converter needs its own licence); candidates are GDAL (MIT) and PDFium or pdf.js, never AGPL renderers; the implementing library is proposed in a comment here for approval before use. Runs server-side as a durable job (<issue id="a626308a-598f-41ba-accd-4004cbbd9932" label="EVE-54" href="https://linear.app/resnovas/issue/EVE-54/p18c-build-durable-agent-runs-on-effect-cluster-and-workflow" />).
6. `BasemapTiles` and `ImageryTiles` ports with the providers chosen in <issue id="75206124-f123-452e-baa0-2c8ec3d42e59" label="EVE-120" href="https://linear.app/resnovas/issue/EVE-120/f100-spike-map-engine-with-offline-tiles-and-yjs-bound-editing-on-expo" />; tile URLs and keys come from config (<issue id="9d08c369-bac9-4eb7-b8a7-329b5ec9bff0" label="EVE-41" href="https://linear.app/resnovas/issue/EVE-41/p12-build-app-config-settings-secrets-and-credentials" />), never source.
7. Geocode an address to a site anchor through the `Geocoder` port.

## Acceptance criteria

* Property tests: WGS84 to local and back round-trips within 1 mm across a 5 km radius; calibration of a synthetic plan with known transform recovers it within 0.05 m.
* A PDF fixture and a DXF fixture import and calibrate; the residual is shown and stored.
* A second tenant cannot read the site (tenant guard test); a vendor role cannot call `site.update` (permission test).
* Each action passes the <issue id="dc89a6af-338c-417b-a352-80cbfb05ec1e" label="EVE-40" href="https://linear.app/resnovas/issue/EVE-40/p11-build-the-action-contract-and-inventory-in-effect-schema" /> parity check and is callable over HTTP and MCP with the same result.
