## Goal

The agent plans, chases and reschedules event work for people, using only the task actions and approvals a person has, and tells them when it cannot act offline.

## Context

* Parent spec: <issue id="4e19a499-139f-4016-88c4-264d3a0f7c33" label="EVE-62" href="https://linear.app/resnovas/issue/EVE-62/f3-tasks-task-lists-assignments-dependencies-and-checklists-per-event" /> section 7 (agent behaviour) and section 4 (approval policies).
* Agent turn loop and durable runs from <issue id="3deaef52-8db8-490c-8143-b293ab5656a8" label="EVE-52" href="https://linear.app/resnovas/issue/EVE-52/p18a-build-the-agent-turn-loop-with-actions-as-tools" /> and <issue id="a626308a-598f-41ba-accd-4004cbbd9932" label="EVE-54" href="https://linear.app/resnovas/issue/EVE-54/p18c-build-durable-agent-runs-on-effect-cluster-and-workflow" />; screen context from F3.5 (<issue id="1bd1df6b-b667-44f0-a5c5-5c560cec94e4" label="EVE-86" href="https://linear.app/resnovas/issue/EVE-86/f35-build-the-task-screens-with-screen-projections-on-web-and-mobile" />).

## Scope

1. Task skill for the agent: descriptions and examples for every task action, plus guidance on approvals (never sign off, confirm before assigning others, confirm bulk over 10 and template creation over 25).
2. On request: "plan this Event from this brief" (draft list, preview, then create with confirm), "what is blocking X" (`dependency.blockers`), "move everything after load-in by a day" (`task.reschedule` preview then confirm), "reassign Sam's tasks to Alex" (confirm), "make a checklist from this PDF" ([EVE-25](<https://linear.app/resnovas/issue/EVE-25/port-files-private-attachments-artifacts-and-document-import>) import then `checklist.addItem`).
3. Proactive, opt-in per user behind `tasks-agent-proactive`: a daily digest of the user's overdue and due-soon tasks; a warning when a dependency chain makes a due date impossible; a nudge when a checklist is incomplete at its Segment anchor (F1, <issue id="fbcff205-decd-464a-b8ab-a1278e71fbe4" label="EVE-73" href="https://linear.app/resnovas/issue/EVE-73/f1-events-and-production-planning-the-event-record-run-of-show" />). Proactive runs only read and suggest; proposed writes wait for the user.
4. Offline: the on-device agent can run local task actions; anything needing a remote model returns an "offline, will run when connected" message instead of pretending.
5. Evaluation cases ([EVE-29](<https://linear.app/resnovas/issue/EVE-29/port-agent-evaluations-linked-to-posthog-datasets>) when ported; local fixtures until then) for the scenarios above, including refusal of sign-off and of assigning outside permissions.

## Acceptance criteria

* Each on-request scenario passes an evaluation run with the right actions called and the right confirms raised.
* The agent acting for a crew member refuses to assign someone else and explains why.
* The digest for a user with 3 overdue tasks lists exactly those 3 and makes no writes.
* With the device offline and no local model, the agent says the plan request is queued and creates nothing.
* Success metric wired: share of agent task writes not undone within 24 hours (<issue id="4e19a499-139f-4016-88c4-264d3a0f7c33" label="EVE-62" href="https://linear.app/resnovas/issue/EVE-62/f3-tasks-task-lists-assignments-dependencies-and-checklists-per-event" /> section 10).
