## Goal

The agent turns a brief ("8,000 standing, two stages, one day, licensed bar") into a draft layout a person can review and apply, reuses past layouts as templates, and warns when the plan stops meeting the rules.

## Scope

1. `sitemap.layout.draft`: a durable run that reads the brief, the site boundary, existing locked layers and the rule set, and writes proposed placements to a new draft layer only; returns the draft layer id, a findings list and quantities. Deterministic placement helpers (along a line, grid, spacing, keep-clear buffers) are pure functions the model calls as tools; the model chooses, the helpers compute geometry.
2. Apply flow: the person reviews the draft layer, then `feature.placeMany` (confirm above 50) copies accepted items to target layers; reject deletes the draft layer.
3. `sitemap.template.save` and `.apply` (confirm on a non-empty map): templates are parametric (scale facility counts by attendance, anchor to boundary edges) so a festival layout adapts to a new field.
4. Proactive checks: on edit batches, F1 attendance changes and F8 sales milestones, run `check.run` and notify the owner of new blocking findings through <issue id="9aae6a50-4a43-4327-ae6a-51d18bc69b35" label="EVE-24" href="https://linear.app/resnovas/issue/EVE-24/port-notifications-messaging-channels-and-transactional-email" />, rate-limited to one digest per hour per map.
5. Agent skills doc (ai-docs): how to read the `sitemap.editor.v1` projection, which actions need approval, how to explain findings.
6. Evaluation set (with <issue id="bef04957-8bec-479e-85ee-5880dfc9fc8c" label="EVE-29" href="https://linear.app/resnovas/issue/EVE-29/port-agent-evaluations-linked-to-posthog-datasets" /> when available): 10 briefs on 3 fixture sites, scored on zero blocking findings, quantities within 10 percent of a reference plan, and no edits outside the draft layer.

## Acceptance criteria

* For the 10 briefs, the draft never writes outside its draft layer, and at least 8 have zero blocking findings.
* Applying a draft is undoable in one step.
* A template saved from site A applied to site B scales facility counts with attendance and stays inside B's boundary.
* Proactive digest fires once for a seeded over-capacity change and not again within the hour.
