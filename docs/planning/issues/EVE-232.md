## Linear description

## Goal

For small events with no lighting console, Eventiva itself sets simple lighting levels on cue, from the patch already in the plan, through the show bridge.

## Context

* Parent: <issue id="fbcff205-decd-464a-b8ab-a1278e71fbe4" label="EVE-73" href="https://linear.app/resnovas/issue/EVE-73/f1-events-and-production-planning-the-event-record-run-of-show" /> decision D1, decided 2026-11-08 by Jonathan: option C, so this slice is in scope.
* Uses the patch from F1.7 and the bridge from F1.13. sACN (ANSI E1.31) and Art-Net are UDP protocols carrying 512-channel DMX universes.

## Scope

1. `DmxOutput` transport layer in the show bridge for sACN (multicast and unicast, priority, source name) and Art-Net (ArtDmx unicast), written on plain `dgram` without a new dependency.
2. Looks: a `Look` record per event (fixture ids with intensity and, for colour-mixing fixtures, colour from the GDTF mode's channel map) and cues whose target is a look with a fade time. Simple intensity and colour only; no effects engine, no moving-light programming.
3. Output engine in the bridge: frame rate 30 to 44 Hz, crossfades between looks, highest-takes-precedence merging off; a blackout-safe `show.stopAll` that fades to a configured safe look.
4. Safety: output only while armed; on heartbeat loss hold the last look (configurable to fade to safe), never jump to full.
5. Actions: `look.create`, `look.update`, `look.delete`, `look.preview` (on screen only), plus `cue.fire` targets of type look.
6. Screen: Looks (fixture grid with intensity and colour, preview) with projection and bound controls.

## Acceptance criteria

* A capture of sACN and Art-Net packets matches the protocol layouts for a 3-universe show.
* A 2 second fade between two looks produces a monotonic ramp at the configured frame rate.
* Disarming or heartbeat loss behaves as configured and never outputs full.
* Screen passes the unbound-control check and axe.

## Constraints

Effect-TS v3 house rules (fade maths pure TypeScript); every operation is an inventory action with one permission check, audit and change record; UI from Rambo-UI, WCAG 2.2 AA; behind PostHog flag `f1-show-control-dmx` with default off; no new dependency without Jonathan approving it on this issue; whitelabel ASCII copy; people docs and ai-docs in the same commit; ships to main with `node --run check` results here.

## Done signal

Merged with packet, fade and safety tests green and a test against a real sACN node recorded here.
