## Goal

Schedulers see people against time across events, drag to assign, and see gaps and rule breaches at a glance, while the agent sees exactly the same board.

## Context

* Slice 6 of F2 (<issue id="1c8c53a0-396b-43a7-8fb9-c138dbbc70b2" label="EVE-67" href="https://linear.app/resnovas/issue/EVE-67/f2-scheduling-and-rosters-crew-availability-shifts-offers-call-sheets" /> section 6). Components come from Rambo-UI (D8); ResourceTimeline does not exist yet and is requested there as a neutral component.
* Screen awareness contract from <issue id="91297309-acc4-4bb9-ad68-33fbc2720e5a" label="EVE-50" href="https://linear.app/resnovas/issue/EVE-50/p111-build-screen-awareness-app-state-navigation-and-the-screen" />; presence from <issue id="a1348819-43cc-4005-8e8d-a896a761af03" label="EVE-51" href="https://linear.app/resnovas/issue/EVE-51/p112-build-collaboration-yjs-for-text-and-canvas-with-record-sync-and" />.

## Scope

1. Roster board: rows per person (or per requirement), columns per hour or day, shifts as blocks, unfilled requirement lane, rule results as badges, filters by event, department, role.
2. Drag to assign calls `roster.assign`; context menu for unassign, offer, override; toolbar for `roster.propose` (F2.11 when present) and `roster.confirm`.
3. Projection: visible range, rows, shifts, selection, unfilled counts and rule results in view, masked by the viewer's permissions.
4. Presence: other schedulers' cursors and selections on the same event (<issue id="a1348819-43cc-4005-8e8d-a896a761af03" label="EVE-51" href="https://linear.app/resnovas/issue/EVE-51/p112-build-collaboration-yjs-for-text-and-canvas-with-record-sync-and" />).
5. Navigation actions `nav.open roster.board` and `nav.open event.staffing` with filters as parameters.
6. Works on web, Android and tablet layout; phone shows a list view of the same data.
7. Rambo-UI issue filed for ResourceTimeline with the neutral interaction hooks.

## Acceptance criteria

* The agent answers "what is unfilled on screen" from the projection and assigns by action id with the same result as a drag.
* Two schedulers on one event see each other's presence and edits within 2 seconds online.
* Keyboard-only assignment is possible (WCAG 2.2 AA, 2.1.1 and 2.5.7 dragging alternative).
* 300 people by 14 days renders and scrolls at 60 fps on a mid-range Android device (recorded).

## Constraints

UI from Rambo-UI only; Effect for IO; behind flag `f2-scheduling`; no new dependency without approval here; ships to main with `node --run check` results and device notes pasted here.
