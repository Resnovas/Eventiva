## Linear description

## Goal

The agent can do every payroll step a person can, explains any pay figure in plain words, and spots likely mistakes before a run is locked, while never locking, submitting or paying without a human.

## Scope

1. A payroll skill for the agent: how to prepare a run, read exceptions, use `payroll.run.explainLine`, and which actions need approval.
2. Proactive suggestions behind `payroll-agent-suggestions` (default off), each a suggestion card the user accepts or dismisses: hours versus roster over threshold, missing clock-out, working-time limit, below-minimum effective rate, freelancer without engagement status, run total versus last comparable run over threshold (default 20 percent).
3. Approval gates: confirm that every `always` action fails for the agent without a recorded human approval, across UI chat, MCP inbound (<issue id="37c126a9-64e0-4235-88f0-494533c8e3a2" label="EVE-48" href="https://linear.app/resnovas/issue/EVE-48/p19-build-inbound-mcp-from-the-action-inventory" />) and ACP inbound (<issue id="937d4311-ff71-4bd1-b167-846d08afc64f" label="EVE-49" href="https://linear.app/resnovas/issue/EVE-49/p110-build-inbound-acp-so-editors-can-drive-eventivas-agent" />).
4. Evaluation set: 20 questions ("why is Sam's pay higher this week", "what did night crew cost on event X") with expected answers, linked to PostHog datasets via <issue id="bef04957-8bec-479e-85ee-5880dfc9fc8c" label="EVE-29" href="https://linear.app/resnovas/issue/EVE-29/port-agent-evaluations-linked-to-posthog-datasets" />.
5. Privacy: the agent acting for a worker sees only that worker; prompts and telemetry carry no amounts or names by default.

## Acceptance criteria

* The agent prepares a run for the fixture and stops at lock with an approval request.
* Each proactive check fires on a seeded case and stays silent on a clean one.
* The evaluation set passes at 90 percent or better and is wired into CI as a report, not a gate.
* A worker's agent asking for another worker's pay gets a permission error on every interface.
