## Goal

When an event sells out, fans join a waiting list, and returned or resold tickets go to the next person at face value, so organisers fill every place and touts gain nothing.

## Context

* Parent <issue id="8bd88b8d-9173-4f07-a92d-1c317836f4b2" label="EVE-76" href="https://linear.app/resnovas/issue/EVE-76/f8-ticketing-ticket-types-capacity-issuance-admissions-and-scanning" /> decision D4; market reference: DICE resells returns at face value through its waiting list.
* Compliance: UK Consumer Rights Act 2015 s.90 to 95 information duties for resale; prices never above face value plus the organiser's stated fee (<issue id="8bd88b8d-9173-4f07-a92d-1c317836f4b2" label="EVE-76" href="https://linear.app/resnovas/issue/EVE-76/f8-ticketing-ticket-types-capacity-issuance-admissions-and-scanning" /> section 11).

## Scope

1. WaitlistEntry and ResaleListing schemas.
2. Actions: ticketing.waitlist.join, leave, offer; ticketing.resale.list, withdraw.
3. Automatic mode (organiser setting): when capacity frees (hold expiry, refund, resale listing) the next entry gets an offer with a hold for a set time (default 30 minutes), notified via <issue id="9aae6a50-4a43-4327-ae6a-51d18bc69b35" label="EVE-24" href="https://linear.app/resnovas/issue/EVE-24/port-notifications-messaging-channels-and-transactional-email" />; manual mode uses waitlist.offer.
4. Resale: holder lists a ticket; when a waiting buyer pays through F9 at face value, F9 refunds the seller (minus the organiser's resale fee if set), F8 voids the old ticket and issues a new one to the buyer, all in one durable workflow with compensation on failure.
5. Waiting list screen for organisers; join and resale controls on My tickets and the public ticket picker.

## Acceptance criteria

* Refund of one ticket in a sold-out pool sends an offer to the first entry within 10 seconds; unanswered offers pass to the next entry after expiry.
* A resale completes with buyer ticket valid, seller ticket void and seller refunded; a failure after payment rolls back to the seller keeping a valid ticket and the buyer refunded.
* Resale price cannot exceed face value plus the stated fee (typed error).
* Agent can recommend offers and run waitlist.offer only with confirmation.
