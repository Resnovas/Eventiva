## Linear description

## Goal

An organiser publishes a site as an immutable version that loads fast, works without client JavaScript for static content, meets WCAG 2.2 AA, can be previewed privately first and rolled back in one step.

## Context

## Scope

1. `sites.publish` (server-only, durable workflow): resolve every page doc to a block tree, validate props and bindings, check path uniqueness, run the publish checks, write an immutable SiteVersion (content hash, publishedBy, note), hand it to the `SiteHosting` port (F14.11) and purge caches. Agent approval `confirm`.
2. Publish checks that block: axe serious or critical issues, missing alt text, skipped heading levels, contrast below AA against the brand kit, broken internal links, a form without consent text, content checks for credential-harvesting forms and known-bad links (abuse rule, section 11). Warnings that do not block: large images, missing SEO description.
3. Renderer service: server-side render of a SiteVersion page through react-native-web plus the `site-blocks` renderers; static HTML and CSS, with islands that hydrate only interactive blocks (ticket selector, form, map, accordion if needed). Data blocks fetched at render per F14.9 caching.
4. `sites.preview`: expiring signed link (default 7 days) rendering the current draft or a chosen version, `noindex`.
5. `sites.rollback`: make an earlier version live again (new version entry pointing to the old snapshot), `confirm`.
6. `sites.versions.list` and `.diff` (block-level diff with changed props) for the Version history screen.
7. Telemetry: `site_published`, `site_rolled_back`; render spans carry site and version ids only.

## Acceptance criteria

* A reference event site (home, schedule, tickets, form, five content pages) scores at least 95 for performance and accessibility in Lighthouse on mobile, passes axe with no serious issues, and its content pages render with JavaScript disabled (recorded here).
* Publishing a page with a missing alt text is refused with a list of failures; fixing it and republishing succeeds.
* A preview link shows the draft and stops working after expiry; it is never indexed (`noindex` header test).
* Rollback restores the previous version within one minute at the edge.
