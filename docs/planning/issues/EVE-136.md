## Linear description

## Goal

Crew can pick up open shifts and hand over or swap shifts with each other, with the scheduler approving and the rules still enforced.

## Context

* Slice 8 of F2 (<issue id="1c8c53a0-396b-43a7-8fb9-c138dbbc70b2" label="EVE-67" href="https://linear.app/resnovas/issue/EVE-67/f2-scheduling-and-rosters-crew-availability-shifts-offers-call-sheets" /> section 4). Uses the assignment state machine (F2.4) and rules engine (F2.3).

## Scope

1. `shift.open.post` publishes an unfilled shift to eligible people (role and qualifications match, rules pass); `shift.open.claim` creates a proposed assignment, first valid claim wins, server authoritative.
2. `swap.request` (to a named person or open), `swap.offer`, `swap.accept`, `swap.approve` (approval always, crew chief or `roster:approve`).
3. Rules run on both sides of a swap; a swap that breaks a block rule cannot be approved without an override.
4. Notifications to eligible people and to the approver through <issue id="9aae6a50-4a43-4327-ae6a-51d18bc69b35" label="EVE-24" href="https://linear.app/resnovas/issue/EVE-24/port-notifications-messaging-channels-and-transactional-email" />.
5. Open shifts and swaps screen with projection.

## Acceptance criteria

* Two people claim one open shift at once; exactly one gets it, the other gets a typed `AlreadyClaimed` result.
* A swap leaving one person under 11 hours rest shows the block and needs an override.
* The agent can request a swap for the user but cannot approve it.
