## Goal

A person edits a site map on web, desktop, tablet or phone with mouse, touch or keyboard, and the agent sees exactly what they see and can press every control they can.

## Context

* Parent <issue id="f8432c08-24bb-4690-a3e1-16ed79977eee" label="EVE-108" href="https://linear.app/resnovas/issue/EVE-108/f10-interactive-site-maps" /> section 6 (Map editor, Site setup, Sites list). Screen awareness contract from <issue id="91297309-acc4-4bb9-ad68-33fbc2720e5a" label="EVE-50" href="https://linear.app/resnovas/issue/EVE-50/p111-build-screen-awareness-app-state-navigation-and-the-screen" />; components from Rambo-UI (D8), which stays free of Eventiva dependencies and exposes neutral interaction hooks.
* Engine wrapped by the `MapEngine` port from <issue id="75206124-f123-452e-baa0-2c8ec3d42e59" label="EVE-120" href="https://linear.app/resnovas/issue/EVE-120/f100-spike-map-engine-with-offline-tiles-and-yjs-bound-editing-on-expo" />.

## Scope

1. Rambo-UI components (in Resnovas/Rambo-UI, proposed there as their own issue if missing): `MapCanvas` (wraps the engine through a neutral adapter prop), `LayerList`, `SymbolPalette`, `Inspector`, `Toolbar`, `PointPairPicker`.
2. Eventiva screens: Sites list, Site setup and calibration, Map editor, with every control bound to the action ids in <issue id="f8432c08-24bb-4690-a3e1-16ed79977eee" label="EVE-108" href="https://linear.app/resnovas/issue/EVE-108/f10-interactive-site-maps" /> section 6.
3. Screen-context projection `sitemap.editor.v1`: map id, phase, viewport bbox and zoom in site-local metres, visible and locked layers, active tool, selection (feature ids, labels, symbol, linked entity), the latest check findings count. Selection and viewport changes publish to application state; the projection is filtered by layer audience.
4. Tools: select, pan, place symbol, draw line, draw polygon, measure, multi-select, snap to grid and to other features, nudge with arrow keys (0.1 m, 1 m with shift), rotate with handles or keys.
5. Navigation actions `nav.open sitemap.site` and `nav.open sitemap.map` with an optional viewport, shared with the command menu.
6. Responsive: inspector as side panel on wide screens, bottom sheet on phones.

## Acceptance criteria

* On web and Android, the agent answers "what am I looking at" from the projection (layers, selection, area in view) and performs placement, move and delete by action id with the same result as the gesture.
* An unbound editor control fails the <issue id="91297309-acc4-4bb9-ad68-33fbc2720e5a" label="EVE-50" href="https://linear.app/resnovas/issue/EVE-50/p111-build-screen-awareness-app-state-navigation-and-the-screen" /> check on a fixture.
* Keyboard-only placement, selection, move and delete work on web; axe reports no serious issues; focus is visible on every control.
* Frame time stays under 16 ms median with 2,000 features on the <issue id="75206124-f123-452e-baa0-2c8ec3d42e59" label="EVE-120" href="https://linear.app/resnovas/issue/EVE-120/f100-spike-map-engine-with-offline-tiles-and-yjs-bound-editing-on-expo" /> reference device.
