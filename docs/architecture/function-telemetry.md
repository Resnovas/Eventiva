## Primitive API and bounded evidence

The candidate is exposed only through `@eventiva/runtime/function-instrumentation`. `functionCatalog(names)` lazily admits static operation names and returns an opaque handle; `functionObservation(handle, name)` lazily prepares a native Effect operator. Apply that operator to the returned named generator Effect, never as an Effect.fn definition pipeable. All invocations require the existing Flags service and caller Scope. Business success/error/environment types remain inferred, with instrumentation admission failures added. Pure scalar helpers intentionally become lazy Effects; receiver/argument/arity preservation does not promise an unchanged scalar API. Synchronous-only framework contracts remain BLOCKED for the later migration.

```ts
import { FlagsSafeDefaults } from '@eventiva/contracts/flags';
import { functionCatalog, functionObservation } from '@eventiva/runtime/function-instrumentation';
import { Effect } from 'effect';

const calculate = Effect.fn('example.calculate')(function* (left: number, right: number) {
    return yield* Effect.succeed(left * 10 + right);
});
const program = Effect.scoped(Effect.gen(function* () {
    const catalog = yield* functionCatalog(['example.calculate']);
    const observe = yield* functionObservation(catalog, 'example.calculate');
    return yield* calculate(4, 1).pipe(observe);
})).pipe(Effect.provide(FlagsSafeDefaults));
```

This primitive installs no sink, exporter or provider and never enables remote export. Arbitrary external tracers are not a supported replacement for that privacy boundary. Names must match the static lowercase catalog syntax, have1..96characters and fit the **target-wide union** of8192, including `telemetry.function.catalog` and `telemetry.function.prepare`. Separate handles cannot reset capacity or evict names. Rejected input consumes no catalog slots and exposes only fixed reason codes. Duplicate/helper-reserved/invalid/overflow names fail with reason `catalog`; preparing a nonmember fails `operation` before business execution. Reuse handles/prepared operators rather than preparing per invocation.

Counters, metrics, traces, spans and attributes have independent public declarations in `functionSignalFlags`, each safe-default TRUE through existing Flags. Both trace and span flags, and ambient tracing enablement, must permit native spans. Attributes contain only the static `eventiva.function.source=generator` declaration; ambient annotations and metric labels are not copied into these observations. Counters are `started`/`completed`; `executions` is independently metric-gated. All use fixed `eventiva.function.*` names and an admitted `operation` label. Completion uses native ensuring/Exit finalization on every exit. The terminal metric programs introduce no authored callback and never invoke either generator helper.
